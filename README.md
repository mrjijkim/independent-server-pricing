## 同样是物理机，价格为什么能差十倍以上

决定月费高低的主要是五件事，搞清楚它们，看价格表就知道钱花在哪了。

1. **CPU 代际**。$27 和 $249 的差距，很大程度上就是 L5640 和 Raptor Lake 的差距。老平台跑得动网站和轻服务，跑不动力计算和数据库高负载。
2. **带宽与流量的搭配**。低价档标配 1Gbps 端口配 10–30TB 月流量；“不限流量”往往伴随低带宽，比如 ZJI 香港和 MOACK 韩国都是 30Mbps 不限；想要 10Gbps 端口，得看 spinservers（$49，@30T）或 Sharktech 高防方案。
3. **线路**。同样是海外机房，默认中国优化线路的方案溢价明显：raksmart 日本高防 $109/月起就是默认中国优化线路，Krypt 硅谷 China Direct 从 $175 起。低价美国独服基本不含回国优化，这正是它便宜的原因之一。
4. **防御能力**。ReliableSite 免费 20Gbps DDoS 防护算入门；专业高防如 Sharktech，$199/月起给到最高 1T 防御。业务容易被攻击，这笔钱省不得。
5. **隐藏的一次性费用**。最容易踩的坑在这里。JustHost 的独服标价 759 元/月起，看似不高，但价格表注明安装费按服务器费用的 50% 一次性收取且不可退款——500 美元的机器，首月内取消也只退 250 美元。比价时月费和一次性成本要分开算。

## 独立服务器价格常见问题

### 独立服务器一个月大概多少钱？

便宜的每月 27–60 美元（美国老平台配置促销价），存储型和高防型 69–199 美元起，中国优化线路或新平台 CPU 在 160–400 美元区间，香港机房人民币 300–700 元/月是常见水位。

### 便宜独立服务器有什么要注意的？

主要盯三点：一次性安装费（问清楚是否收取、可否退款）、流量配额和超额政策、线路是否有回国优化。三点里任何一点没确认，都别急着付款。

### RackNerd 的便宜独服能装 Windows 吗？

能。这套机器提供 IPMI 远程管理，官方支持安装 Proxmox、VMware ESXi、Windows、Linux 等系统，装虚拟化平台开小鸡也没问题。

### 独立服务器和 VPS 的价格差在哪？

物理机整台资源归你一个人用，成本没法分摊，所以价格下限远高于 VPS。月付几十美元的独服听起来贵，换来的是不与任何邻居抢 CPU、内存和磁盘 IO，对稳定性和合规要求高的业务，这笔差价通常花得值。
